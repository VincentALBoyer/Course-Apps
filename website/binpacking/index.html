📦 Greedy Bin Packing — Game

5 rounds · one bin · maximum profit

Drag items into a fixed bin and pack as much profit as you can. Each round is harder than the last. The perfect layout is too hard to work out by hand, so go with your gut, and notice which rule of thumb you end up using.

How it works

  1. 🖱️ Drag & drop Drag items from the list into the bin. Move them, rotate them with ⟳, or drag them back to remove them.
  2. 💰 Read the colors Pale items are worth little and deep red ones are worth a lot. Hover any item for its exact size and profit.
  3. ⚠️ Stay in bounds Overlaps are fine while you work, but if any remain when the round ends, that round scores 0.
  4. 🏆 Score Your score is the total profit you pack across all 5 rounds. Your time is tracked too.

Class code (optional)

Everyone who enters the same code in the same mode gets exactly the same rounds, so you can compete with your class on total score. Clear it for random rounds.

🧪 Challenge Mode — Instance Generator

Offline · reproducible · solve with code

Generate a batch of bin-packing instances and solve them with your own algorithm. The rules are the same as the game: one fixed bin per instance, maximize profit, and no overlaps or out-of-bounds placements.

How it works

  1. 🎲 Pick your settings The same seed always gives the same batch. Higher difficulty means a bigger bin and more items, and level 10 reaches the hundreds.
  2. 📥 Download & solve You get one Excel row per item. Fill in x, y and rotated (TRUE/FALSE) for every item you pack, and leave skipped items blank.
  3. 📊 Get graded Upload the filled-in file in the Scoring tab. Any instance with an overlap or an out-of-bounds item scores 0.

📊 Scoring Mode — Grade a Submission

Graded in your browser · nothing is uploaded

Upload your completed instances file from Challenge mode, with the x / y / rotated columns filled in, to get your score and look at each layout.

How grading works

  1. 🧮 Each instance on its own Every instance is scored separately. Its profit is the total value of the items you packed.
  2. ⚠️ Feasible or zero Any overlapping or out-of-bounds item makes that instance score 0, however well the rest was packed.
  3. 🔏 Integrity check The file is checked against the signature recorded when it was generated, which flags any change to bin sizes, item sizes or profits.
