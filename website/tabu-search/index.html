🔀 Tabu Search: The Grid Game

Tabu search · build, swap, remember

Build a connected path of cells (up, down, left, right, no revisits) that maximizes the sum of its values. Then improve it one swap at a time, while a tabu list stops you from undoing your recent moves, so you can escape a local optimum instead of cycling straight back to it.

How it works

  1. 🧭 Build a path Click cells one by one to build your initial solution: a connected path of a fixed length.
  2. 🔁 Swap to improve Each move takes one cell out and puts one cell in, as long as the path stays connected.
  3. 🚫 Tabu memory A removed cell can't come back for tenure moves, so you can't undo a move straight away.
  4. 🌟 Aspiration A tabu move is allowed anyway if it beats the best solution so far.
